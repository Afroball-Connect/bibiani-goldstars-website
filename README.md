# Bibiani Gold Stars SC — Next.js

A responsive Next.js App Router website concept for Bibiani Gold Stars SC.

## Run locally

- `npm install`
- `npm run dev` and open `http://localhost:3000`
- `npm run typecheck` and `npm run build` for verification

The supplied crest is served locally from `public/assets/crest.jpg`. The supplied 1280×720 hero image is served as `public/assets/goldstars-hero.jpg`; it is treated as illustrative imagery, not a verified photograph of a specific match. Club facts and the 2024–25 title milestone are based on the Wikipedia page supplied with the brief. Fixture details remain unconfirmed. The `/squad` page uses clearly marked fictional sample names, roles, shirt numbers, ages, heights, preferred feet, favourite foods and staff appointments, with anonymous silhouette illustrations; it is not a verified roster, and the demo data must be replaced with club-confirmed information before any person is presented as a real player or staff member. The `/shop` page is a clearly labelled visual concept with no live products, prices, stock, orders, payments or fulfilment. Confirm roster, staff appointments, official merchandise, approved imagery and rights with the club before treating this concept as an official publication.
